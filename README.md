# 🔹 AutoFinCalc
> **Enterprise-Grade Car Finance Calculator built with ABP.IO**

AutoFinCalc is a modular, open-source car finance calculator designed for real-world use in dealerships, lending institutions, or private vehicle sales. Built on the robust ABP.IO framework, it showcases enterprise-level architecture, modular design, and clean code practices — making it ideal for both demonstration and extension.

---

## 🚀 Features

- Loan repayment breakdowns (monthly, total interest, balloon payments)
- Dynamic calculation engine with customizable rates and terms
- Clean ABP.IO layered architecture (Domain, Application, UI)
- Authentication & role-based access via Identity
- Exportable repayment schedules (PDF / Excel ready) 
- Built with scalability and modularity in mind

---

## 🛠 Tech Stack

- **Backend**: ASP.NET Core (.NET 8), ABP.IO
- **Frontend**: Angular  (modular setup)
- **Database**: PostgreSQL  (EF Core)
- **Auth**: ABP Identity / JWT
- **Hosting Ready**: Azure, Vercel, Docker

---

## 📘 Use Cases

- Portfolio & CV showcase
- Starting point for vehicle loan products
- Teaching tool for ABP.IO-based project structure
